# ⚡ Gifza AI Platform

ระบบสแกนตัดตารางสติกเกอร์ 6x5 อัจฉริยะ, แปลงภาพเป็นอนิเมชัน GIF, และจัดการระบบ API Token ระดับองค์กร

## 🚀 ขับเคลื่อนด้วยสมองกล
- **Vela Core Engine** (พัฒนาและออกแบบสถาปัตยกรรมโดย ธันวา ภูปิงบุตร / พ่อเหน่ง)

## 📂 โครงสร้างระบบ
- `index.html` - หน้าแรก (Landing Page) ดีไซน์พรีเมียม
- `app.html` - หน้า Workspace Studio (ตัดตาราง 6x5 & สร้าง GIF)
- `pricing.html` - หน้าแพ็กเกจราคาและระบบชำระเงิน
- `api.html` - หน้าจัดการ Token และเอกสาร API
